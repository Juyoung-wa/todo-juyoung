# ⚽ 주영의 할 일 목록

선수가 찬 공이 골문에 들어가기 직전, 그 찰나의 순간을 배경으로 한 할 일 목록 웹앱이에요.
할 일은 Supabase에 저장돼서 새로고침해도 사라지지 않아요.

**배포 주소:** https://todo-juyoung.vercel.app

## 주요 기능

- **할 일 추가·완료·삭제:** 입력하고 Enter, 체크박스로 완료, ✕로 삭제
- **두 번 눌러 고치기:** 할 일 글자를 두 번 누르면 고칠 수 있어요. Enter는 저장, Esc는 취소
- **작성자 이름 (선택):** 할 일 아래 작은 글씨로 `✎ 이름`이 보여요
- **마감일 (선택):** 마감이 가까운 순서로 정렬되고, 마감일이 없는 할 일은 아래로 가요
  - `D-3`, `오늘`, `2일 지남`처럼 남은 날짜를 보여 주고, 오늘 마감은 주황, 지난 마감은 빨강
- **골라 보기:** 전체 · 진행 중 · 완료 버튼과 남은 할 일 개수
- **전광판:** 남은 할 일과 완료한 할 일 수를 점수판처럼 보여 줘요
- **한글 입력 배려:** 한글을 조합하는 중에 Enter를 눌러도 두 번 처리되지 않아요
- **오류 표시:** 저장에 실패하면 빨간 상자로 알려 주고, 입력한 글자는 남겨 둬요

## 사용 기술

- **HTML / CSS / JavaScript** — 프레임워크나 라이브러리 없이 브라우저 기본 기능만 사용
- **Supabase** — 할 일을 저장하는 데이터베이스 (`fetch`로 REST API 직접 호출)
- **Vercel** — GitHub에 올리면 자동으로 배포

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면의 뼈대와 배경 그림(SVG) |
| `style.css` | 카드, 버튼, 목록 등 꾸밈 |
| `script.js` | 할 일 불러오기·추가·고치기·삭제, 정렬과 골라 보기 |
| `config.js` | Supabase 주소와 publishable key |
| `CLAUDE.md` | Claude Code에게 주는 프로젝트 규칙 |
| `.mcp.json` | Claude Code의 Supabase 연결 설정 (토큰 없음) |

## 보안 주의

- **지금은 누구나 할 일을 읽고, 추가하고, 고치고, 지울 수 있어요.**
  로그인 없이 쓰도록 Supabase `todos` 표의 권한 규칙(RLS 정책)을 열어 두었기 때문이에요.
  배포 주소를 아는 사람은 누구나 데이터를 바꿀 수 있으니, 개인 정보나 중요한 내용은 넣지 마세요.
- `config.js`의 **publishable key는 공개돼도 괜찮은 열쇠**예요. 실제로 할 수 있는 일은 권한 규칙이 정해요.
- **secret key(`sb_secret_...`)나 service_role 키는 절대 이 저장소에 넣지 마세요.**
  권한 규칙을 무시하는 관리자 열쇠라서, 새어 나가면 데이터베이스 전체가 위험해져요.
